Simple Python Calculator
This program is a basic command-line calculator that allows users to perform arithmetic operations on two numbers. It is designed for continuous use, allowing the user to perform multiple calculations in a single session.

Features
Arithmetic Operations: Supports Addition (+), Subtraction (-), Division (/), and Multiplication (*).

Continuous Loop: The program prompts the user after each calculation to decide whether they wish to perform another operation or exit the program.

How to Use
Run the script: Execute the Python file in your terminal or IDE.

Enter Numbers: When prompted, enter your first and second numbers.

Choose Operation: Type the symbol for the operation you wish to perform (+, -, /, or *).

View Result: The program will print the calculated result.

Continue or Exit: You will be asked if you wish to continue. Enter Y to start a new calculation or any other key (or N) to close the program.

Note
The program performs integer input conversion. Ensure you enter valid numbers to avoid runtime errors.

The division operation uses standard floating-point division. Be aware that dividing by zero will result in an error.
